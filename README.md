# Pemrograman Web Lanjut

Repository tugas mata kuliah **Pemrograman Web Lanjut** — Teknik Informatika, Politeknik Negeri Jakarta.

Setiap tugas dikumpulkan dalam folder terpisah sesuai pertemuan, agar mudah ditelusuri per minggu/topik.

## Struktur Folder

```
.
├── Tugas_Pertemuan-6/
│   ├── koneksi.php
│   └── edit.php.php
└── ...
```

## Cara Menjalankan

1. Jalankan Laragon (Apache + MySQL aktif)
2. Clone/salin repo ini ke dalam folder `www` Laragon
3. Buat database sesuai nama yang dipakai di masing-masing `koneksi.php` (default: `latihan`)
4. Buka folder tugas yang dituju lewat browser, contoh:
   ```
   http://localhost/<nama-folder-repo>/Pertemuan-4/tabel_mahasiswa.php
   ```
